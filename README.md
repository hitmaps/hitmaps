# HITMAPS

Interactive maps for the Hitman series.

- The website is in [frontend](frontend/). Setup notes are in [frontend/README.md](frontend/README.md). The site app itself is [frontend/hitmapsdotcom](frontend/hitmapsdotcom/).
- The API is in [backend](backend/). Setup notes are in [backend/README.md](backend/README.md).

History from both `hitmaps/hitmaps` and `hitmaps/hitmaps-backend` is kept. Commits from before this layout still have files at the repository root.
